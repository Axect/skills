# Sources

Survey of public research and academic writing skills, read from the original files on 2026-11-06. Stars are GitHub repository stars (`gh api repos/OWNER/REPO`); installs are per skill on skills.sh, read the same day. Popularity explains where the survey looked; it is not evidence that a rule works. Licence evidence is what was found in the repository; where none was found, nothing was copied and ideas were restated with attribution. Rule IDs refer to `rules.md`.

Counting: the table lists 22 repositories whose writing rules were read, plus openai/skills, which was checked and has no prose skill. Two catalogues that only point to other skills were also read and are not listed (InternScience/Awesome-Scientific-Skills, WenyuChiou/ai-research-skills).
